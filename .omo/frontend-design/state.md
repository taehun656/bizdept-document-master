# Frontend Design State

- Surface: local browser wizard for business document setup.
- Reference lineage: slide-master Confirm UI workflow; beUI choice/upload/button interaction states.
- Style: minimalist document desk; borders and tonal layers; no gradients or decorative shadows.
- Desktop structure: bounded two-pane shell. Preview pane and settings pane each own vertical scrolling.
- Narrow structure: one document scroll, preview above settings.
- Accent: cobalt blue. Typography: Korean system sans for controls, Korean serif only for preview title.
- Primary task: save topic, template, style, outputs, and attachments to `spec/ui-selection.json`.
- Accessibility baseline: semantic native controls, visible focus, non-color selection cues, live status, reduced motion.
